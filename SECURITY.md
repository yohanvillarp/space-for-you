# Security Policy

## Supported Versions

Only the latest active release branch receives security updates and critical patches.

| Version | Supported          |
| :------ | :----------------- |
| main    | Yes                |
| develop | Active Development |
| < 1.0.0 | No                 |

---

## Reporting a Vulnerability

We take the security of **Space for You** and user data seriously. If you discover a vulnerability or security flaw, please report it privately rather than creating a public GitHub issue.

### How to Report

1. Send an email to the project maintainer at `yohannikel21@gmail.com` with the subject line: `[SECURITY] Space for You Vulnerability Report`.
2. Include the following details in your report:
   - A detailed description of the vulnerability.
   - Exact steps or proof-of-concept (PoC) scripts to reproduce the issue.
   - Any potential impact on user data or application integrity.
   - Recommended mitigations, if known.

### Response Timeline

- **Initial acknowledgment:** Within 48 hours of receipt.
- **Triage and assessment:** Within 5 business days.
- **Fix and patch deployment:** As soon as possible depending on severity, typically within 14 business days.

---

## Responsible Disclosure

We kindly ask that you keep information about any discovered vulnerability confidential until the maintainers have investigated, addressed, and deployed a fix. We appreciate your cooperation in protecting users of Space for You.
